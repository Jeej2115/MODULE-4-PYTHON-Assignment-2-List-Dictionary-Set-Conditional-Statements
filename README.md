# Python Data Structures and Conditional Statements

## 📌 Assignment Overview

As a Python learner, this assignment focuses on understanding and working with core Python data structures such as **Lists, Dictionaries, and Sets**, along with implementing **conditional statements** using `if`, `elif`, and `else`.

The assignment provides practical experience in creating, accessing, modifying, and performing operations on different Python data structures. It also demonstrates how conditional statements can be used to make decisions based on user input.

---

## 🎯 Objectives

The main objectives of this assignment are to develop a strong understanding of:

* List creation, modification, and access operations
* Dictionary creation and manipulation using key-value pairs
* Set properties and operations such as uniqueness, union, and intersection
* Decision-making using `if`, `elif`, and `else` statements
* Taking input from the user and displaying appropriate outputs
* Applying Python concepts through practical programming exercises

---

## 🛠️ Topics Covered

### 1. Lists

The assignment demonstrates:

* Creating lists
* Accessing list elements using indexes
* Appending elements
* Inserting elements
* Removing elements
* Popping elements
* Extending lists
* Sorting lists
* Finding maximum and minimum values
* Calculating the sum of list elements

### 2. Dictionaries

The assignment demonstrates:

* Creating dictionaries
* Storing data using key-value pairs
* Accessing dictionary values
* Adding new key-value pairs
* Updating existing values
* Using `keys()`, `values()`, and `items()` methods

### 3. Sets

The assignment demonstrates:

* Creating sets
* Understanding uniqueness of set elements
* Removing duplicate values automatically
* Understanding why sets cannot be accessed using indexes
* Performing union operations
* Performing intersection operations

### 4. Conditional Statements

The assignment demonstrates decision-making using:

* `if`
* `elif`
* `else`

A performance category program is implemented based on a user's score:

| Score          | Performance Category |
| -------------- | -------------------- |
| Greater than 7 | Above Average        |
| 4 to 7         | Average              |
| Less than 4    | Below Average        |
